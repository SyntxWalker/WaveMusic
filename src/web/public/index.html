COMMANDS

Complete Command Reference

Use either Slash commands (/) or your server's prefix commands (default !).

Command Slash Version Description Example
!play <query> /play Play from YouTube, Spotify, or query !play Starboy The Weeknd
!search <query> /search Search and pick from top 5 tracks via select menu !search Bohemian Rhapsody
!247 /247 Toggle 24/7 voice channel lock (stays 24/7) !247
!lyrics [song] /lyrics Fetch lyrics for current track or song title !lyrics Blinding Lights
!prefix <symbol> /prefix View or change server bot command prefix !prefix ?
!pause /pause Pause currently playing audio !pause
!resume /resume Resume paused audio playback !resume
!skip /skip Skip to the next song in the queue !skip
!stop /stop Stop playback, clear queue, and leave VC !stop
!loop [mode] /loop Toggle repeat mode (off, track, queue) !loop track
!queue /queue View upcoming tracks with pagination !queue
!volume <0-150> /volume Adjust playback volume !volume 80
!shuffle /shuffle Randomize upcoming queue tracks !shuffle
!nowplaying /nowplaying Display the live Miniplayer embed !nowplaying
!clear /clear Clear upcoming tracks from queue !clear
!stats /stats View latency, uptime, memory, and players !stats
